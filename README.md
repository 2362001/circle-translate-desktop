# Circle Translate Desktop - Tesseract OCR (Free & Offline)

## ✅ Đã chuyển sang Tesseract.js!

Ứng dụng hiện tại hoàn toàn miễn phí và không cần Google Cloud Vision API.

### 📋 Các bước cài đặt:

#### **Bước 1: Cài đặt dependencies**

```bash
npm install
```

#### **Bước 2: Chạy app**

```bash
npm start
```

### 🎯 Cách sử dụng:

```
1. Nhấn Alt+Shift+C
2. Vẽ vòng tròn quanh văn bản BẤT KỲ trên màn hình
3. Thả chuột
4. Tesseract OCR tự động nhận diện
5. Dịch (qua API MyMemory miễn phí) và hiển thị kết quả
```

### ✨ Tính năng:

- ✅ **Vẽ vòng tròn** → Tự động nhận diện text
- ✅ **Không cần bôi đen** - OCR tự động
- ✅ **Miễn phí 100%** - Không cần API Key cho OCR
- ✅ **Hoạt động mọi app** - Word, PDF, Game, Ảnh...
- ✅ **Hỗ trợ Tiếng Anh & Tiếng Việt**

### 🛠 Công nghệ:

- **Electron**: Framework chính.
- **Tesseract.js**: Công cụ OCR chạy local.
- **MyMemory API**: Công cụ dịch thuật (Free).
